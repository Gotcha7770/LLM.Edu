# LLM Practice

## Подготовка окружения

1) В терминале выполните `nvidia-smi` и посмотрите «CUDA Version» в правом верхнем углу.
2) Установить CUDA Toolkit 13.x с сайта [NVIDIA][2].

[2]: https://developer.nvidia.com/cuda-downloads
